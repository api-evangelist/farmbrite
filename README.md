Farmbrite provides all‑in‑one farm management software designed for modern farmers to run thriving crop and livestock operations. The platform integrates field planning, livestock tracking, inventory, sales, and reporting into a single cloud‑based solution, helping users increase productivity, reduce busywork, and grow their businesses. Start a free trial to experience the comprehensive tools for farm management.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Farmbrite: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
